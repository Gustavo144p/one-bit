# Starbucks Clone (OneBit)

Projeto educacional em React (Create React App).

## Como rodar

```bash
npm install
npm start
```

Abre em http://localhost:3000

## Estrutura

- `src/components/api.js` — produtos (dados)
- `src/components/assets.js` — imagens e logo
- `src/components/format.js` — formatação de preço (R$)
- `src/components/header.jsx`, `home.jsx`, `footer.jsx`, `button.jsx`
- `src/App.jsx` — estado do carrinho (salvo no localStorage)
